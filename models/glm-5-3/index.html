Can my GPU run GLM-5.3?

GLM-5.3 has 753B parameters, about 51.2B active per token. As published in FP8 the weights take 704 GiB. With 32K tokens of context it needs 16 × H100 80 GB, 8 × H200 141 GB, 4 × B300 288 GB and more than 16 × L40S 48 GB. It doesn't fit on any single GPU, even in INT4.

  • It uses multi-head latent attention, so its KV cache is far smaller than a standard model of the same size. With tensor parallelism each GPU keeps a full copy of it; data-parallel attention fits more context.
  • The published weights are FP8, native on Ada, Hopper, Blackwell and MI300 or newer. A100s run FP8 as weight-only.

Questions

How much VRAM does GLM-5.3 need?

The weights take 704 GiB as published (FP8), 1.37 TiB in BF16, 717 GiB in FP8 and 374 GiB in INT4. On top of that, the KV cache adds about 97.5 KiB per token: 3.05 GiB for one 32K-token request and 12.2 GiB at 128K. Serving engines also need a few GiB per GPU for activations.

Can GLM-5.3 run on a single H100?

No. Even in INT4 the weights (374 GiB) don't fit in the ~70 GiB an H100 can use. As published it needs 16 H100s.

Can I run GLM-5.3 on an RTX 4090 or a Mac?

It doesn't fit on one RTX 4090 (24 GB), even in INT4. It's too large even for a 512 GB Mac Studio in INT4.

How much context can GLM-5.3 handle on 8 × H200 141 GB?

One request can use up to 382K tokens (the model's limit is 1M). At 32K tokens per request, about 11 requests fit in memory at once.
