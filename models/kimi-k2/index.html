Can my GPU run Kimi-K2?

Kimi-K2 has 1.03T parameters, about 32.9B active per token. As published in FP8 the weights take 959 GiB. With 32K tokens of context it needs 16 × H100 80 GB, 8 × H200 141 GB, 8 × B300 288 GB and more than 16 × L40S 48 GB. It doesn't fit on any single GPU, even in INT4.

  • It uses multi-head latent attention, so its KV cache is far smaller than a standard model of the same size. With tensor parallelism each GPU keeps a full copy of it; data-parallel attention fits more context.
  • The published weights are FP8, native on Ada, Hopper, Blackwell and MI300 or newer. A100s run FP8 as weight-only.

Questions

How much VRAM does Kimi-K2 need?

The weights take 959 GiB as published (FP8), 1.87 TiB in BF16, 977 GiB in FP8 and 510 GiB in INT4. On top of that, the KV cache adds about 68.6 KiB per token: 2.14 GiB for one 32K-token request and 8.58 GiB at 128K. Serving engines also need a few GiB per GPU for activations.

Can Kimi-K2 run on a single H100?

No. Even in INT4 the weights (510 GiB) don't fit in the ~70 GiB an H100 can use. As published it needs 16 H100s.

Can I run Kimi-K2 on an RTX 4090 or a Mac?

It doesn't fit on one RTX 4090 (24 GB), even in INT4. It's too large even for a 512 GB Mac Studio in INT4.

How much context can Kimi-K2 handle on 8 × H200 141 GB?

One request can use up to 67K tokens (the model's limit is 128K). At 32K tokens per request, about 2 requests fit in memory at once.
